# RMS Communications - Easy Payments

Flutter Android app for RMS Communications.

## GitHub / Codemagic

1. Upload this folder to a GitHub repository.
2. Connect the repository to Codemagic.
3. Select the `android-release` workflow from `codemagic.yaml`.
4. Start a build.
5. Download `app-release.apk` from Artifacts.

## Important

- This repository does NOT contain any Pay2All API token.
- Keep the Pay2All token on your backend/server only.
- The current app UI can be built and installed independently; live recharge requires the backend/API endpoint to be configured.
